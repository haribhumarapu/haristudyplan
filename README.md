# HariStudyPlan Landing Page

A premium SaaS landing page for HariStudyPlan - an AI-powered study planner for GATE, SSC CGL, Coding Interviews, and Career Growth.

## Features

- **Modern Dark Theme**: Professional design with slate, blue, purple, and green color palette
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices
- **Sticky Navigation**: Always accessible navigation with smooth scrolling
- **Hero Section**: Compelling headline and CTA buttons with demo preview
- **Dashboard Preview**: Interactive dashboard mockup showing study tracking
- **Statistics Section**: Key metrics and achievements
- **Premium Features**: Six feature cards with smooth animations
- **Framer Motion Animations**: Smooth, professional transitions and interactions
- **Hover Effects**: Interactive elements for better UX
- **Production-Ready**: Clean, maintainable, and scalable code

## Tech Stack

- **React 18** with TypeScript
- **Tailwind CSS** for styling
- **Framer Motion** for animations
- **Lucide React** for icons
- **Vite** for fast development

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
